## 📖 项目简介

本项目是一个基于 **Qt6** 和 **C++** 开发的校园导航系统，实现了校园景点的可视化展示、最短路径查询、多类型筛选等功能。系统主要采用 **Dijkstra算法** 计算最短路径，使用 **邻接矩阵** 存储景点间的道路信息，并提供了友好的图形化交互界面，管理员默认密码：admin123。

---

## ✨ 功能特点

### 🗺️ 地图可视化
- 以图形化方式展示校园景点和道路

### 🔍 路径查询
- **最短路径查询**：Dijkstra算法，高亮显示路径
- **所有路径查询**：DFS算法，列出所有可达路径
- **附近景点查询**：按类型筛选最近的景点

### 🏷️ 景点分类
支持10种景点类型

### 🔧 管理员功能
- 添加/删除景点
- 修改景点信息
- 增删改景点间道路
- 自动保存到文件
